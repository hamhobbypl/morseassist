MorseASSIST 0.001 BETA - Windows x64

INSTALLATION
Installed for the current user in %LOCALAPPDATA%\Programs\MorseASSIST.
MorseASSIST has its own Start menu and optional desktop shortcuts, settings,
logs, macros, licence files and uninstall entry, separate from MorseCONSOLE.
Existing personal settings are preserved during updates and uninstallation.

REQUIREMENTS AND HAMLIB
Windows 10 or 11, 64-bit; .NET Framework 4.7.2 or later; Hamlib for Windows
64-bit; and the appropriate USB driver for your radio.
Download Hamlib from the official releases:
https://github.com/Hamlib/Hamlib/releases
Recommended order: install Hamlib first, then MorseASSIST.
You may install Hamlib afterwards, but BEFORE the first CAT connection.
Restart MorseASSIST after installing Hamlib. An existing Hamlib installation
is detected automatically; there is no need to reinstall it.
Hamlib and radio USB drivers are not included in this installer.

RADIO AND AUDIO
Select the exact radio model, CAT COM port and audio devices in Settings.
MorseASSIST starts its own local Hamlib server on port 4533 and stops its
owned server on CAT disconnect or application exit.
Two applications cannot use the same radio COM port simultaneously.
Disconnect CAT or close the first application before connecting the other.
CW transmission uses USB audio and Hamlib PTT. Check routing and transmit
settings before use. Incorrect settings may cause unintended transmission.
The user is responsible for safe equipment operation and compliance with
applicable radio rules. Read the included Terms-of-use.txt before use.

DEMO AND PURCHASE
Each demo session lasts 10 minutes, starting with the first decoded word.
Audio activity, the spectrum and an unfinished word do not start the timer.
Restart the application for another 10-minute session. Sessions are unlimited.
Pay only if the application already meets your expectations and you accept
this BETA's current state, behaviour, limitations and available functions.
Registration only removes the demo time limit. It adds NO new features and
fixes NO problems. Do not pay expecting activation to change the software.
The same licence key works in MorseASSIST and MorseCONSOLE for the same
registered email and callsign. Activate the key separately in each application.

DEFAULT DISPLAY
Spectrum colour: Amber. Waterfall palette: Amber.
Existing saved colours and other user preferences are preserved.
The horizontal waterfall can be switched on/off above CW DECODER.
